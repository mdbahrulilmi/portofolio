# Hasanah Tours - System Enhancement & GHG Integration

**Hasanah Tours** adalah platform layanan perjalanan umroh dan wisata religi yang sedang dalam tahap pengembangan berkelanjutan. Dalam proyek ini, saya berperan untuk **melanjutkan, memperbaiki, dan mengoptimalkan** sistem yang sudah berjalan (PHP Native), serta melakukan ekspansi fitur melalui integrasi layanan **Gohalal-Go (GHG)** pada portal khusus [program.hasanahtours.com](https://program.hasanahtours.com).

---

## 🛠️ Peran & Tanggung Jawab

Fokus utama saya adalah modernisasi dan penyesuaian fungsionalitas sistem agar lebih relevan dengan kebutuhan bisnis saat ini:

*   **UI/UX Refactoring:** Melakukan modernisasi tampilan pada sistem berbasis **PHP Native**. Saya mengubah struktur *style* HTML dan CSS lama agar tampil lebih bersih, responsif, dan mudah digunakan oleh staf operasional maupun jamaah.
*   **Feature Expansion:** Mengembangkan modul baru untuk membedakan alur layanan, di mana platform kini mampu menangani program spesifik hasil kolaborasi eksklusif **GHG x Hasanah Tours**.
*   **Performance & Logic Patching:** Melakukan *debugging* dan perbaikan logika bisnis (termasuk perbaikan pada *Cekat AI* dan alur verifikasi) untuk memastikan sistem berjalan lebih akurat dan minim *error*.
*   **Modernization (React Bridge):** Mengembangkan modul interaktif baru menggunakan **React** untuk memberikan pengalaman pengguna yang lebih dinamis pada bagian *user-facing*, tanpa harus melakukan *rewrite* total pada *backend* PHP yang sudah stabil.

---

## 🚀 Fitur Integrasi & Pengembangan

1. **GHG x Hasanah Tours Portal**
   * Membangun portal khusus di [program.hasanahtours.com](https://program.hasanahtours.com) yang menjadi pusat integrasi layanan **Gohalal-Go**.
   * Sinkronisasi data paket perjalanan sehingga penawaran dari GHG dapat dikelola dan ditampilkan langsung melalui ekosistem Hasanah Tours.

2. **UI & Logic Enhancement**
   * Perubahan total pada gaya visual HTML untuk meningkatkan kemudahan navigasi sistem admin.
   * Perbaikan *logic* pada fitur-fitur kritis seperti *Cekat AI* dan manajemen pendaftaran jamaah agar proses *input* data lebih efisien.

3. **Modern Frontend Integration**
   * Mengintegrasikan modul React ke dalam struktur PHP untuk menangani *input* data dan pemilihan paket yang kompleks agar lebih interaktif.
   * Memastikan transisi antara halaman berbasis PHP dan React terasa halus (seamless).

4. **Optimasi Sistem Legacy**
   * Perbaikan *query* database untuk meningkatkan kecepatan pemuatan data jamaah yang semakin bertambah.
   * Patching bug pada alur sistem pendaftaran yang sebelumnya sering terkendala pada validasi data.

---

## 💻 Tech Stack & Workflow

* **Legacy Backend:** PHP Native & MySQL
* **Modern Integration:** React.js (untuk modul portal GHG)
* **Logic/AI Patching:** Optimasi fitur Cekat AI & Algoritma Validasi
* **Styling:** CSS Custom & Tailwind (untuk modernisasi tampilan)
* **Connectivity:** REST API Integration

---

## 🤝 Tantangan & Fokus Pengembangan

* **System Synergy:** Menyelaraskan *coding style* antara skrip PHP Native lama dengan modul React baru agar tetap *maintainable*.
* **Business Logic Adjustment:** Menyesuaikan alur sistem lama agar bisa mengakomodasi program baru hasil kolaborasi **GHG x Hasanah Tours**.
* **Stability:** Memastikan perbaikan *bug* kecil pada sistem lama tidak merusak alur transaksi yang sedang berjalan.
